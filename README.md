# Catherine Dequito — Virtual Assistant & Creative Portfolio

A responsive static portfolio website built with HTML, CSS, and vanilla JavaScript. Ready for GitHub Pages.

## Included
- `index.html` — portfolio content and sections
- `styles.css` — responsive styling, gold/pink palette, serif headlines and Poppins body type
- `script.js` — mobile navigation, portfolio filters, and current-year footer
- `assets/` — page images rendered from the supplied portfolio PDF, plus a portrait crop from the supplied portfolio page

## Before publishing
1. Open `index.html` locally in a browser and review the content and image crop.
2. The website uses `catherinedequito22@gmail.com` from the supplied résumé for its email buttons.
3. The Google Drive sample links are copied/reconstructed from the supplied portfolio PDF. Check that the folders/files are shared with the people you want to reach.
4. Google Fonts are loaded online; fallback fonts are included if they are unavailable.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com.
2. Create a new **public** repository, for example `catherine-portfolio`.
3. Upload the contents of this ZIP (the files inside the `catherine-va-portfolio` folder, not the ZIP itself). Keep `index.html` at the repository root and keep the `assets` folder intact.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait a minute or two and refresh the Pages section. GitHub will show the public website URL, usually `https://YOUR-USERNAME.github.io/catherine-portfolio/`.
8. Open the URL on both desktop and mobile. Test navigation, category filters, email button, telephone link, sample images, and Google Drive links.

## Updating the website
Edit `index.html`, `styles.css`, or `script.js`, then upload/commit the changes to the same repository. GitHub Pages republishes automatically after a short delay.

## Notes
- No invented performance outcomes were added. The highlights use the figures stated in the supplied résumé/portfolio: 97,000+ YouTube subscribers, 10+ clients mentioned in the portfolio, and 3+ years of experience.
- The work gallery uses faithful images of pages from the supplied PDF to avoid unnecessarily altering your original samples. Selecting a sample opens the full image; video and blog cards open their associated sample links.
- This is a static website. The email button opens the visitor's email app; it does not send email automatically or require a backend.
